# gnatstub

Code generated by LALVM calls the GNAT runtime when a language check fails
(`__gnat_rcheck_CE_Overflow_Check`, `__gnat_rcheck_CE_Range_Check`,
`__gnat_rcheck_CE_Divide_By_Zero`). `libgnatstub.a` defines these three symbols
so that a program bound by LALVM links without the GNAT runtime. Each one prints
the message GNAT prints for an unhandled exception and exits with status 1:

```
raised CONSTRAINT_ERROR : <file>:<line> overflow check failed
```

This is a temporary substitute, until LALVM's own Ada runtime provides the
proper support. The `gnatstub` CMake target builds the archive into
`<build>/lib/`.
